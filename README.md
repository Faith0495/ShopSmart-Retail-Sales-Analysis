\## Lookup Analysis



An interactive Lookup Analysis worksheet was created using

Excel lookup functions to retrieve information from related

datasets.



To use this worksheet, the user only needs to change the

Order ID in the designated input cell.



Once a valid Order ID is entered, the lookup formulas

automatically retrieve the corresponding order details,

including customer, product, store and other related

information.



This feature allows users to search for specific orders

without manually navigating through multiple worksheets.



Note: The entered Order ID must exist in the Orders dataset

for the lookup formulas to return matching information.
